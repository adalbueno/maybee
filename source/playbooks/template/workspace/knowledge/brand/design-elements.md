# Design elements

Design here means being distinct: the repeated elements that let someone recognize you at a glance. Pick them from your real life, and keep each one coherent with who you are.

Each element is one of two kinds:

- **Functional:** changes how you write, such as short sentences or paragraphs that start in lowercase. The agent applies these in every text.
- **Cosmetic:** a recognizable decoration, such as an emoji, a color, a nickname or an object. The agent uses these only when they fit, not in every line.

| Element | Category | Kind | Where it applies |
|---|---|---|---|
| | Writing | Functional | |
| | Formatting | Functional | |
| | Visual | Cosmetic | |
| | Personal (object, phrase, nickname) | Cosmetic | |

Categories: **visual** (colors, photo style), **formatting** (how a text is laid out), **writing** (tone, length, how paragraphs start), **personal** (an everyday object, a signature phrase, a nickname, an emoji).

## How to find yours

- Everyday objects that are peculiar to you.
- Phrases you say all the time.
- The way you already write, when you are not trying.
