# Audience

Who this project is for. Keep **one file per person you serve**: copy [persona.md](persona.md), rename the copy after the person (`busy-founders.md`), and fill it in.

Write the way they talk, not the way you would describe them in a report. Real phrases from messages, comments and calls are worth more than clean wording.

Start with one persona. Add a second only when it is truly a different person with different pains.
