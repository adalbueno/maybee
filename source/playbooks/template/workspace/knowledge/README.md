# Knowledge

What this project knows about its world. Each folder is one subject, and the agent reads them before it writes anything for you.

- [audience/](audience/README.md): who this is for, in their own words.
- [offer/](offer/README.md): what you give people, and in which steps.
- [brand/](brand/README.md): how you sound and what makes you recognizable.

Fill them in over time. A half-filled file is fine: leave a section empty until you know the answer, and the agent will skip it instead of guessing. Choices you make along the way go in [decisions/](../decisions/README.md).
