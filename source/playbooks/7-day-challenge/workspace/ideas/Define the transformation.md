# Define the transformation

**Challenge index:** [Start here](7-day%20challenge%20%E2%80%94%20start%20here.md) · **Next:** [Decide who the challenge is for](Decide%20who%20the%20challenge%20is%20for.md)

Before deciding the audience, rules or daily posts, write the transformation the challenge is designed to create.

1. **Starting point:** what is true or difficult before day 1?
2. **Finish point:** what will participants be able to show, do or decide by the end of day 7?
3. **Proof:** what visible work or evidence shows that the transformation happened?
4. **Next problem:** once participants reach this result, what problem becomes visible next? Use it to keep this challenge focused and save the next problem for a later challenge when it does not belong here.

Write the transformation in one sentence:

> In 7 days, [these participants] move from [starting point] to [visible result], and can show [proof].

**Done when:** the sentence is specific enough to determine what each day must help participants do.
