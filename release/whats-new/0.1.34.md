# What's new in Maybee 0.1.34

**Change the project by asking, from About.**

- **A chat on About.** Write what should change (the voice, the audience, the offer, the brand, a decision, the knowledge notes) and the assistant edits the right file straight away and logs it in the changelog. If it is not clear which file, it asks.
- **Updated marks.** A file the chat changed shows "Updated" with the time in the Memory list, until you open it or a day passes.
- **Files are links.** A file named in the reply opens when you click it.
- **Questions work too.** Ask what is left to do or what the project knows, and it answers without changing anything.
