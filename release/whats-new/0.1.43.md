# What's new in Maybee 0.1.43

**One clear AI action per card, quick capture from anywhere on the board, and a bee that celebrates finished work.**

- **A new welcome.** Maybee opens on a welcome screen with the bee, then asks your name and what you are working on in one open question. While your assistant reads your answer, Maybee shows how you will work together: catch the idea, pick the next step, get it done. No more question about how your writing should sound. If no assistant is connected yet, the board opens directly, and the welcome chat starts when one connects.
- **One AI action per column.** Each card offers the one step its column needs: **Explore this idea** in Maybe, **Get it ready to start** in Next, **Do the next step** in Now, **What comes next?** in Done. Explore also gives a rough idea a clear title and description first.
- **The action is on the chat bar.** Open a card and its action is right there in yellow, without opening the chat. Start typing and the same spot turns into Send. An action you already asked for leaves the bar.
- **Capture from the bottom of the board.** A bar under all the columns, like the chat on About: write an idea, press Enter, and the board shows the new card in Maybe, highlighted. The cursor stays there for the next one.
- **The bee celebrates.** When the assistant finishes a request and its card is in Done, the bee at the top spins and a burst of pollen flies out.
- **A calmer activity list.** The list behind the bee shows one short row per card, with the latest request and how many there were. Click a row and the card opens with its chat showing.
- **Fewer windows on the membership check.** The automatic check never opens a window. Only the button opens Skool, and only when you need to log in.
- **Maybee repairs itself.** When something fails, your assistant fixes the known problems by itself (a stuck listener, Codex from the Microsoft Store, the sandbox). For anything else, it prepares a bug report for the Maybee team as a GitHub link, already filled in, with personal data removed. You read it and decide whether to send it.
- **Windows:** a listener that crashed no longer blocks the next one, and Codex from the Microsoft Store gets a second try with a setting that lets it run commands.

**Done when:** you have read this and moved the card to Done. Nothing is required from you.
