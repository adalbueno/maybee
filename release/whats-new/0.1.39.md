# What's new in Maybee 0.1.39

**Playbooks are zip files you import. A new workspace always starts from the default template.**

- **A correction to 0.1.38.** The notes said **Add workspace** offers a list of playbooks. It does not: a new workspace always starts from the default template, with no choice to make.
- **Playbooks are separate from Maybee.** They no longer travel inside the Maybee package. Each one is a `.zip` that you import into the workspace you have open with **Import playbook** in the workspace menu. Files you already have are never overwritten, and routines come in with auto-run off.
- **The 7-day challenge is a playbook.** Run a 7-day challenge for your community or audience: one card in **Now** explains it, and **Next** has every step in order. Download `playbook-7-day-challenge.zip` from this release's page on GitHub and import it.

**Done when:** you have read this and moved the card to Done. Nothing is required from you.
