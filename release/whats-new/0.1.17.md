# What's new in Maybee 0.1.17

**Maybee's program files are now protected, and every update tells you what changed.**

- **A card like this one for every update.** When Maybee updates, a card appears in Now with what is new. Read it, then move it to Done. If you skip a few versions, you get a card for each of the latest ones. The full history is always in [RELEASES.md](../RELEASES.md).
- **Maybee's program files are locked.** They are read-only now, and your assistant is told not to change them, even if you ask it to improve Maybee. Maybee gets better through updates. Your own notes, ideas and files are not affected: your assistant keeps working on them as before.
- **Smaller and quicker to set up.** Maybee now arrives ready to run, so setting it up on a new machine installs one dependency instead of dozens.
- **Your assistant knows how cards work.** Maybee now includes a short guide for it, so the cards it creates or changes look right on the board.
- **A tidier folder.** What Maybee saves while it runs, such as requests and snapshots, now lives in `.maybee/data/`, next to the program and not inside it. Your existing data is carried over.
- **The workspace list is cleaner.** It shows Default and the workspaces you created, nothing else.
- **Fixed text in the starter cards.** Some cards showed stray folder paths in the middle of sentences. They read normally now.

**Done when:** you have read this and moved the card to Done. Nothing is required from you.
