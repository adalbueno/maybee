# What's new in Maybee 0.1.35

**Run and Ask AI reach the agent you already work with: Codex or Claude Code.**

- **Codex works.** Start the bridge from your Codex session and each request from the board goes back to that same session, with its context. The agent that answers and its session show in the status tray ("Codex · 01a1e4…").
- **A session open in a window.** Codex does not let a second process take over a session that is open. Maybee then answers from a fork of it, keeps going in that fork, and says so in the tray. The answers show in the app, not in your open window.
- **Nothing is lost when an agent fails.** If the run ends without an answer, or takes too long, the request is closed with a reply that says why.
- **Claude works as before.** Only the start command adds `--agent claude`.
- **Not tried yet:** an interactive Codex session starting the bridge by itself (its sandbox has no network), and the Claude command with the real program.
