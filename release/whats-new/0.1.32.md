# What's new in Maybee 0.1.32

**Sort the Maybe column the way you want, see why a card was set aside, and always know which column a note is in.**

- **Sort Maybe six ways.** The "Sort" menu on the column puts it in order of priority, easy first, value for members, value for business, most recent, or unrated first. A sort replaces the order you set by hand, so Undo appears for a few seconds. You can still drag cards afterwards.
- **A card in Not shows why.** The reason is shown on the card. It comes from the "Why not" field in the note's Settings, or from a "Why not" section in the note.
- **A badge shows the stage.** Next to the title of a note, a small badge shows whether the card is in Maybe, Next, Now, Done, Not or Routine.
- **Replies in the note chat are formatted.** Lists, bold text and code are drawn instead of shown as one block of text.
- **Fixes.** The product file of a new workspace had a description that was not valid, and links with an encoded comma were reported as broken.

**Done when:** you have read this and moved the card to Done. Nothing is required from you.
