# What's new in Maybee 0.1.37

**The skill you install once no longer goes out of date, and the app stays open in Codex.**

- **A small starter.** The `maybee` skill in your home folder is now three files. It does one thing: if the project has Maybee installed, it hands over to the skill that ships inside the package; if not, it installs it. The instructions that change with each version live in the package, so an update of Maybee is an update of how your assistant behaves.
- **Why.** A skill in your home folder wins over the one in the project when the name is the same, so the old text kept being used after an update. That is why an assistant could ignore the new commands.
- **To switch:** install `maybee.zip` of this release once in place of your old `maybee` skill. After that you do not need to touch it again.
- **The app stays open when Codex ends a command.** Codex stops everything a command left running, so the app, the Skool window and the bridge closed together as soon as it finished starting them. Maybee now starts them in a session of their own, on Linux and macOS, and `start.sh` does the same whenever it is run by an assistant (it stays in the foreground in a terminal, or with `--foreground`).
- **Checked on Linux with a real Codex. On macOS it is the same mechanism, but it has not been tried there yet.** If the app still closes on your Mac, tell us.
- **`maybee.sh` says so when it runs inside Codex's sandbox.** It cannot see the app from there, so it asks to be run outside the sandbox instead of reporting "not running" about an app that runs.
