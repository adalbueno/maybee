# What's new in Maybee 0.1.37

**The skill you install once no longer goes out of date.**

- **A small starter.** The `maybee` skill in your home folder is now three files. It does one thing: if the project has Maybee installed, it hands over to the skill that ships inside the package; if not, it installs it. The instructions that change with each version live in the package, so an update of Maybee is an update of how your assistant behaves.
- **Why.** A skill in your home folder wins over the one in the project when the name is the same, so the old text kept being used after an update. That is why an assistant could ignore the new commands.
- **To switch:** install `maybee.zip` of this release once in place of your old `maybee` skill. After that you do not need to touch it again.
- **Nothing changes in the app.**
