# What's new in Maybee 0.1.50

**Attach files in every chat.**

- **Attach a file in any chat.** On the board, in the Inbox, in the Brain and on a card: click the paperclip, drop a file on the bar, or paste a screenshot. Each file shows an icon for its kind. Maybee reads it before it answers.
- **Your files stay in the project.** They are saved in `attachments/`, which the Brain shows. Attaching the same file twice keeps one copy.
- **A file on the board becomes a card.** Attach it in the board's bar and the new idea carries it. Send only the file and the card takes its name.
- **One chat in sight at a time.** With a card open, the chat follows your mouse: over the board you see the board's bar, over the card you see the card's chat.
- **A card can fill the window.** Use the new button next to ✕ to read a long note in full width, and again to put it back beside the page.

**Done when:** you have read this and moved the card to Done. Nothing is required from you.
