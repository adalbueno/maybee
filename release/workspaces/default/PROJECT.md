# Maybee default workspace

## Purpose

This is a ready-to-use starting workspace for moving one project forward with Maybee.

## Who this is for

The person using this workspace to turn real work into clear next actions, ideas, routines and drafts.

## Current goal

Choose one project and one useful next action. Personalize the workspace as you use it.

Maybee reads this folder locally. The files are the source of truth.
