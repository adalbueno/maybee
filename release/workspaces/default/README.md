# Maybee default workspace

This workspace is a small starting playbook for a member of the How I community.

Maybee reads the files here, shows them on the board and helps turn real work into drafts. It never invents facts and never publishes outside the workspace without the owner's approval.

Start with [the overview](ideas/Start%20here%20—%20how%20Maybee%20works.md), then use the cards on the board as the onboarding steps. They explain the columns while you use them: choose a next step, keep an idea in Maybe, configure a Routine, finish the tour, and learn where Not lives. The daily post routine reads [this workspace's changelog](logs/CHANGELOG.md) and prepares a draft for review.

Open the overview card and visit its **Content**, **Settings** and **Changes** tabs. Content explains the note, Settings shows the fields that control the board, and Changes shows the note's history.
