# Maybee default workspace

This workspace is where a new Maybee project starts.

Maybee reads the files here, shows them on the board and helps turn real work into drafts. It never invents facts and never publishes outside the workspace without the owner's approval.

Start with [What is Maybee](ideas/What%20is%20Maybee.md), then take the tour in [How Maybee works](ideas/Start%20here%20—%20how%20Maybee%20works.md), and use the cards on the board as the onboarding steps. They explain the method and the columns while you use them: keep an idea in Maybe, run a routine, finish the tour, and learn where Not lives. The [daily check-in](ideas/Daily%20check-in.md) routine reads the board and suggests the one thing worth doing today.

Open the tour card and visit its **Content**, **Settings** and **Changes** tabs. Content explains the note, Settings shows the fields that control the board, and Changes shows the note's history.
